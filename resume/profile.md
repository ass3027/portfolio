# 이세진

## 간단 소개

Spring Boot와 FastAPI로 시스템을 개발해 온 4년 차 백엔드 개발자입니다. 실무에서는 API, SQL, 복합 인덱스를 개선하고 사전집계를 도입해 통계 화면 표시 시간을 약 40초에서 1.5초로 줄였으며, 영상 장애 확인과 조치에 걸린 시간을 80% 단축했습니다. 개인 프로젝트에서는 FastAPI, SQLAlchemy, PostgreSQL, Redis 기반 서비스를 직접 개발하고 AWS에서 운영하며, 사용자 피드백을 반영해 개선하고 있습니다.

## 핵심 역량

- Python과 FastAPI로 서비스 개발, Spring Boot로 백엔드 설계 및 운영
- SQLAlchemy 2.0 비동기 ORM 사용, 세션과 트랜잭션 관리 공통화
- PostgreSQL에 데이터 저장 및 통계 집계, MariaDB의 SQL과 복합 인덱스 최적화
- Redis 공유 캐시로 조회 부하 제어, Kafka와 Avro로 실시간 데이터 연계
- 로그, Prometheus, Grafana 기반 장애 분석 및 운영 안정화
- 단위 테스트와 통합 테스트로 연동 검증, Docker와 CI/CD로 배포 자동화, AWS 서비스 운영
