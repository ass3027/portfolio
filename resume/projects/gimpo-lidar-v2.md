# 김포공항 LiDAR 실시간 여객 흐름 대기시간 예측

- 기간: 2025.08 ~ 2026.03
- 역할: 풀스택 개발
- 직급: 주임

<a id="query-performance"></a>

## 대용량 통계 화면 조회 개선

약 2,000만 건의 대기시간과 혼잡도 데이터를 다루는 통계 화면에서 결과 표시까지 걸리는 시간을 40초대에서 약 1.5초로 줄였습니다. 차트 조회와 엑셀 출력 API를 분리하고 중복 쿼리를 없애 DB 조회를 4회에서 2회로 줄였으며, EXPLAIN으로 실행 계획을 확인해 날짜 조건과 복합 인덱스의 컬럼 순서를 조정한 결과 약 7초까지 줄었습니다. 쿼리를 개선한 뒤에도 월간 및 연간 통계 요청마다 처리할 데이터가 많아 사전집계 테이블을 도입했습니다.

<a id="receiver-stability"></a>

## C++ gRPC 수신 서비스 안정화

간헐적으로 종료되던 C++ gRPC 수신 서비스의 메모리 사용량을 모니터링해 누수 가능성을 확인했습니다. Visual Studio 디버깅으로 누수 지점을 찾아 수정하고, 예외 처리와 오류 로그를 보강해 간헐적 종료를 해소했습니다.

<a id="prediction-analysis"></a>

## 대기시간 예측 성능 분석 환경 구축

기존 통계로는 대기시간 예측 성능을 평가하기 어려워 필요한 메트릭을 정의하고 수집 범위를 넓혔습니다. Prometheus와 Grafana로 지표를 실시간 확인할 수 있게 했으며, Python으로 CSV 처리와 보고서 생성을 자동화했습니다.

## 기술 스택

Spring Boot, MariaDB, gRPC (C++), Prometheus, Grafana, Python
