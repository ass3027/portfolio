# 신재생에너지 공급인증서(REC) 구매 시스템

- 기간: 2022.08 ~ 2023.06
- 역할: 풀스택 개발
- 직급: 연구원

<a id="purchase-eai"></a>

## 회계 전표 처리와 대금 지급 연계

동서발전, 한국수력원자력, 중부발전을 대상으로 기존 REC 구매 시스템을 전환하는 프로젝트에서 개발을 주로 맡았습니다. 발전사의 REC 구매 건이 회계 전표 처리와 대금 지급으로 이어지도록 EAI 연계를 담당했습니다.

<a id="migration-validation"></a>

## 기존 거래 데이터 이관과 정합성 검증

검증 담당자와 함께 기존 대금 지급 건을 발전 설비, 계약, 전력거래소의 공급인증서 정보와 대조할 기준을 정했습니다. 기존 거래 내역에 이 기준을 적용해 불일치 건을 추렸습니다. 선별한 건은 담당자와 지급 금액, 인증서, 계약 정보를 다시 대조해 불일치를 해결했습니다.
