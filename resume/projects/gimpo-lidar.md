# 김포공항 LiDAR 실시간 여객 흐름 대기시간 예측

- 기간: 2025.08 ~ 2026.03
- 역할: 풀스택 개발
- 직급: 주임

<a id="query-performance"></a>

## 대용량 LiDAR 데이터 조회 성능 개선

약 2,000만 건의 대기시간과 혼잡도 데이터를 조인해 조회하는 통계 화면에서 결과를 표시하기까지 약 40초가 걸렸습니다. API의 불필요한 조회를 줄이고, EXPLAIN으로 실행 계획을 분석해 조회 조건과 복합 인덱스를 개선했습니다. 이후 월간 및 연간 통계에 사전집계 테이블을 도입해 화면 표시 시간을 최종적으로 약 1.5초로 줄였습니다.

<a id="operational-stability"></a>

## 실시간 분석 환경 및 데이터 수신 안정성 개선

대기시간 산출 과정을 분석하기 위해 핵심 메트릭을 정의하고 수집 범위를 넓혔으며, Prometheus와 Grafana로 관측 환경을 구축하고 Python으로 보고서 생성을 자동화해 알고리즘 분석과 개선 시간을 80% 줄였습니다. 간헐적으로 종료되던 C++ gRPC 수신 서비스의 메모리 누수를 수정하고 오류 로그를 추가했으며, 분산된 처리 로직은 백엔드 공통 모듈로 통합했습니다. 수신 서비스의 간헐적 종료를 해소했고, 메모리 사용량과 코드량은 각각 70%, 50% 줄었습니다.

## 기술 스택

Spring Boot, gRPC (C++), MariaDB, Prometheus, Grafana
