# Secuwatcher 영상 반출 솔루션

- 기간: 2026.04 ~ 2026.09
- 역할: PL / 풀스택 개발
- 직급: 주임

<a id="deployment-standardization"></a>

## 다기관 CCTV 시스템 설치 표준화

기술영업 담당자가 개발자 현장 방문 없이 CCTV 영상 반출 시스템을 설치할 수 있게 바꾸고, 최초 설치 시간을 약 4시간에서 1시간으로 줄였습니다. 서버마다 소스를 수정하던 배포 방식을 바꾸기 위해 IP와 경로를 프로파일과 환경변수로 분리하고, 실행 방식이 달랐던 3개 서비스를 Docker 이미지로 구성해 Docker Compose로 설치와 실행을 표준화했습니다. 개발 서버는 CI/CD를 통해 이미지 빌드와 배포를 자동화했습니다.

<a id="project-leadership"></a>

## 배포 구조 설계 및 지자체 내부망 구축

12개 이상 지자체에 적용된 CCTV 영상 반출 솔루션에서 PL을 맡아 업무 배분과 일정을 조율하고, 배포 구조를 직접 설계하고 구현했습니다. 이 중 6개 지자체의 내부망 서버를 직접 구축하고 표준화한 절차로 배포했습니다.

## 기술 스택

Spring Boot, Docker, Docker Compose, Vue.js
