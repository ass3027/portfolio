# Secuwatcher 영상 반출 솔루션

- 기간: 2026.04 ~ 2026.09
- 역할: PL / 풀스택 개발
- 직급: 주임

<a id="deployment-standardization"></a>

## 다기관 CCTV 시스템 배포 표준화 및 CI/CD 구축

CCTV 영상 반출 시스템의 서버별 IP와 경로가 소스에 하드코딩돼 배포할 때마다 수정과 현장 대응이 필요했습니다. 프로파일과 환경변수로 설정을 외부화하고, 실행 방식이 달랐던 3개 서비스를 Docker 이미지로 구성해 내부 경로를 표준화했으며, Docker Compose로 설치와 운영을 통합하고 CI/CD로 이미지 빌드와 개발 서버 배포를 자동화했습니다. 최초 설치 시간을 4시간에서 1시간으로 75% 줄였고, 기술영업 담당자가 개발자 현장 방문 없이 설치할 수 있게 했습니다.

<a id="project-leadership"></a>

## 프로젝트 리딩 및 지자체 내부망 구축

12개 이상 지자체에 적용된 CCTV 영상 수집, 암호화, 마스킹 시스템의 PL을 맡아 업무를 배분하고 일정을 조율했으며, 배포 구조 개선을 주도했습니다. 6개 지자체의 내부망 서버를 직접 구축하고 동일한 배포 방식을 적용해 배포 재현성과 내부 개발 생산성을 높였습니다.

## 기술 스택

Spring Boot, Docker, Vue.js
