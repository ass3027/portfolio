## 개요

LiDAR 데이터로 실시간 여객 위치·인원 수를 체크하고 대기시간을 예측하는 프로젝트. 중간 참여 시점에서 기존 통계 기반 산출 방식으로는 알고리즘 개선·고객사 평가 충족에 한계가 있었다.

C++ gRPC 수신 서비스의 간헐적 종료와 대기시간·혼잡도 로직 분산으로 운영 안정성·유지보수성이 저하된 상태였다.

## 핵심 목표

- ✅ **실시간 메트릭 분석 환경 구축** — 통계 기반 한계 극복 · 분석·개선 시간 **80% 단축**
- ✅ **C++ gRPC 운영 안정성 확보** — 간헐적 종료 **해소**
- ✅ **분산 로직 공통 모듈 통합** — 메모리 **70%↓** · 코드량 **50%↓**

## 기술 스택

`Spring Boot` `gRPC (C++)` `MariaDB` `Prometheus` `Grafana` `Python`

## 핵심 기술적 도전

### 1. 실시간 메트릭 분석 환경 구축

- **문제**: 통계 기반 산출로는 알고리즘 개선에 필요한 인사이트 확보·고객사 평가 충족에 한계가 있었다.
- **성과**: 핵심 메트릭 정의·수집 확장, Prometheus·Grafana 실시간 시각화 + Python CSV 보고 자동화. 분석·개선 시간 **80% 단축**.

### 2. C++ gRPC 메모리 누수 디버깅·수정

- **문제**: C++ gRPC 수신 서비스가 간헐적으로 종료되어 운영 안정성이 저하됐다.
- **성과**: 자원 모니터링으로 누수 확인, 소스 분석·Visual Studio 디버깅으로 수정. 에러 핸들링·로깅 추가로 **간헐적 종료 해소**·신뢰성 향상.

### 3. 혼잡도·대기시간 로직 공통 모듈 통합

- **문제**: 대기시간 기반 혼잡도·세부 처리 로직이 분산·중복되어 유지보수성이 저하됐다.
- **성과**: 분산 로직을 BE 공통 모듈로 통합. 중복 제거로 메모리 **70% 감소**, 코드량 **50% 감소** 및 가독성 개선.
