# FireWatcher: 산불감지 시스템

- **구분**: 스피어에이엑스, 2024.12 ~ 2025.08

---

## 프로젝트 요약

### 개요

CCTV 영상분석으로 산불을 감지하는 시스템. 13개 지역에서 지역별 100대 이상의 CCTV를 운영하는 환경이었다.

영상 끊김이 발생해도 장애 지점과 원인을 신속히 파악할 관측 체계가 부족해 조치에 많은 시간이 소요됐고, DeepStream 분석 모듈이 단일 파일 구조와 전역 변수에 의존해 유지보수와 온보딩이 어려웠다.

### 핵심 목표

- **영상 장애 관측 체계 구축**: 장애 조치 시간 **80% 단축**
- **영상 출력 안정성 향상**: **85% → 93%**
- **분석 모듈 재사용 가능 구조화**: 전역변수 제거, **사내 재사용 가능**

### 기술 스택

`Python / FastAPI` `Kafka / Avro` `FFmpeg` `DeepStream`

### 핵심 기술적 도전

#### 1. 영상 장애 관측 체계 구축

- **문제**: DeepStream 로그 에러는 수동 확인. 비개발 직군은 영상 상태 확인 수단 없음.
- **성과**: 로그 에러 자동 수집 + FastAPI 영상 테스트 시스템 구현, FFmpeg 최적화와 자동 재시작. 장애 조치 시간 **80% 단축**, 출력 안정성 **85→93%**.

#### 2. DeepStream 모듈 리팩터링 + Kafka 전송

- **문제**: 분석 모듈이 단일 파일과 전역 변수에 의존. 유지보수와 온보딩 난이도 높음.
- **성과**: 클래스 단위 분리와 전역 변수 제거, Kafka+Avro Producer-Consumer로 실시간 메타데이터 전송 구조 확립(**사내 재사용 가능**).
