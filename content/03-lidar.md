# 김포공항 LiDAR 기반 실시간 여객 흐름과 대기시간 예측

- **구분**: 스피어에이엑스, 2025.09 ~ 2026.02

---

## 프로젝트 요약

### 개요

LiDAR 데이터로 실시간 여객 위치와 인원 수를 집계하고 대기시간을 예측하는 프로젝트다. 중간 합류 당시 통계 결과만으로는 알고리즘의 문제 지점을 파악하기 어려워 고객사 평가 기준에 맞춘 개선이 더뎠다.

C++ 데이터 중계 서버의 간헐적 종료와 대기시간 및 혼잡도 로직의 분산도 운영 안정성과 유지보수성을 떨어뜨리고 있었다.

### 핵심 목표

- **실시간 메트릭 분석 환경 구축**: 통계 기반 한계 극복, 분석과 개선 시간 **80% 단축**
- **C++ 데이터 중계 서버 안정성 확보**: 간헐적 종료 **해소**
- **분산 로직 공통 모듈 통합**: 메모리 **70%↓**, 코드량 **50%↓**

### 기술 스택

`Spring Boot` `gRPC / C++` `Prometheus / Grafana`

### 실시간 메트릭 수집과 분석 흐름

```
LiDAR 데이터 서버
        │ gRPC
        ▼
C++ 데이터 중계 서버
        │ REST API
        ▼
Backend
        │
        ▼
메트릭 선별·산출
        │
        ├── 메트릭 노출 ──► Prometheus ──► Grafana
        │
        └── 분석 데이터 기록 ──► CSV 로깅 ──► Python 분석 ──► 결과 리포트
```

### 핵심 기술적 도전

#### 1. 실시간 메트릭 분석 환경 구축

- **문제**: 통계 기반 산출로는 알고리즘 개선에 필요한 인사이트 확보와 고객사 평가 충족에 한계.
- **성과**: 핵심 메트릭 정의와 수집 확장, Prometheus와 Grafana 실시간 시각화 + Python CSV 보고 자동화. 분석과 개선 시간 **80% 단축**.

#### 2. C++ 데이터 중계 서버 메모리 누수 디버깅과 수정

- **문제**: C++ 데이터 중계 서버 간헐적 종료. 운영 안정성 저하.
- **성과**: 자원 모니터링으로 누수 확인, 소스 분석과 Visual Studio 디버깅으로 수정. 에러 핸들링과 로깅 추가로 **간헐적 종료 해소**와 신뢰성 향상.

#### 3. 혼잡도와 대기시간 로직 공통 모듈 통합

- **문제**: 대기시간 기반 혼잡도와 세부 처리 로직 분산 및 중복. 유지보수성 저하.
- **성과**: 분산 로직을 BE 공통 모듈로 통합. 중복 제거로 메모리 **70% 감소**, 코드량 **50% 감소** 및 가독성 개선.
