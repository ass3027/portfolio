  • ✅AWS 서비스 조합 기반 실서비스 운영인프라 구성·자동 배포·도메인 연결·운영 비용 조정
  • ✅SDK 없는 RPCN 바이너리 프로토콜 역공학Rust 서버 직접 분석 · 프로토콜 명령 7종 테스트 검증
  • ✅실시간 매칭 상태 시각화스냅샷 Diff 기반 매칭 탐지와 Phantom Room 실시간 노출

개요

N명이 한 좌석을 경합할 때 정확히 1명만 성공시키되(정합성), 그 정확성을 지키면서도 높은 처리량과 낮은 지연을 함께 보장하는(성능) 엔지니어링이 핵심이다. 예매 동시성 보장과 성능을 부하 테스트 실측으로 검증했다.

  • ✅예매 응답 p95 ≤ 500ms실측 348~408ms
  • ✅예매 확정 처리량 ≥ 200 TPS1,000 VU 실측 833~863 TPS
