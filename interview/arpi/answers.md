### 자기소개 예시 초안

안녕하세요. 약 4년간 Spring Boot 기반 서비스를 개발해 온 백엔드 개발자 이세진입니다.

실무에서는 LiDAR와 영상 관련 시스템에서 API 개발과 데이터 연계, 배포 업무를 맡았습니다.

개인 프로젝트에서는 동시성 처리와 클라우드 운영을 직접 다뤘습니다. KTX 티켓팅 프로젝트에서 Redis와 DB의 역할을 나누고, 동시 요청에서 예매 정합성이 유지되는지 부하 테스트로 검증했습니다. Tag2Now는 AWS에 직접 배포해 운영하며 서비스 규모에 맞게 인프라를 조정했습니다.

이러한 개발과 운영 경험을 바탕으로 알피의 분석 서비스 백엔드 개발에 기여하고 싶습니다.

김포공항 LiDAR 프로젝트에서 통계 API 재설계와 조회 성능 개선을 담당했습니다. LiDAR 데이터가 중계 서버를 거쳐 백엔드로 들어오고, 여객 정보와 통계를 제공하는 시스템입니다.
